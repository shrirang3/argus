What's inside

SDKPatches provider client classes at import time — zero call-site changes, third-party code covered too
Non-blockingChat path never awaits the logging path — ingestion down, chat keeps serving
Event-drivenRedis Streams between ingestion and worker, consumer group scales horizontally
IdempotentAt-least-once delivery, deduped at write via event_id + ON CONFLICT DO NOTHING
PII redactionRuns twice — once in the SDK before the event leaves the process, again at the ingestion edge
Multi-providerGroq and Cerebras, open-weight models only, pinned per conversation
KubernetesNamespace, Deployments, StatefulSet for Postgres, host-routed Ingress, HPA on the worker — verified live on a local kind cluster
